비공식 · 아이폰 Safari용

호서 LMS 체크

LMS 화면에 파란 버튼을 띄워 이번 주 과제 · 동영상 출석 · 퀴즈 · 공지를 한 화면에 보여 줘요.

  • 비밀번호를 다루지 않아요
  • 정보는 내 아이폰에만 저장
  • 업데이트는 저절로

Safari에서 열어 주세요

카카오톡이나 다른 앱 안의 화면에서는 설치할 수 없어요.

Safari로 열기

버튼이 안 되면: 화면 구석의 ⋯ 또는 공유 버튼 → Safari로 열기. 아니면 주소를 복사해 Safari 주소창에 붙여 넣으세요.

3단계 · 2분이면 끝나요
  1. 1

    Userscripts 앱 받기

    Safari에 이 스크립트를 넣어 주는 무료 앱이에요 (개발자 Justin Wasack).

    App Store에서 받기

    받은 뒤 앱을 한 번 열어 주세요. 따로 설정할 건 없어요.

  2. 2

    Safari에서 Userscripts 켜기

    아이폰 설정 앱에서:

    설정 → 앱 → Safari → 확장 프로그램 → Userscripts
    1. 확장 프로그램 허용을 켜요
    2. 아래 모든 웹사이트(또는 '기타 웹사이트')를 허용으로 바꿔요

    iOS 17 이하는 설정 → Safari → 확장 프로그램이에요. 다 켰으면 Safari로 돌아와 이 페이지에서 계속하세요.

  3. 3

    스크립트 설치

    스크립트 열기

    코드가 가득한 화면이 열리면:

    1. 주소창의 가가 (또는 ⋯, 퍼즐 모양) → Userscripts
    2. 위쪽 Tap to install → Install
    3. 뒤로 가기로 이 페이지에 돌아오기

    '이 웹사이트에 접근하도록 허용할까요?'가 나오면 항상 허용을 눌러요.

  4. ✓

    LMS에서 확인 · 홈 화면 아이콘(추천)

    LMS 열기

    평소처럼 로그인하면 할 일 화면이 떠요. 처음 한 번은 10~30초 걸려요.

    홈 화면 아이콘 만들기 — 할 일 화면이 뜬 상태에서:

    1. ⋯ 또는 공유 버튼 → 홈 화면에 추가
    2. 웹 앱으로 열기를 끄고 → 추가

    '웹 앱으로 열기'를 켜 두면 Safari 확장이 동작하지 않아 파란 버튼이 안 떠요. 이 아이콘으로 열면 오른쪽 위 ✕ 를 눌렀을 때 탭이 닫혀요.

설치 끝!

이제 LMS에 들어가면 오른쪽 아래 파란 버튼이 보여요. 새 버전은 저절로 받아져서 따로 업데이트할 필요가 없어요.

잘 안 될 때

LMS에 파란 버튼이 안 보여요
  • 2단계(확장 켜기 · 모든 웹사이트 허용)를 다시 확인해 주세요.
  • LMS 화면에서 가가 → Userscripts → 허용(항상 허용)을 누르고 새로고침해요.
  • Userscripts 앱 목록에 hoseo-lms-check가 있는지 봐요. 없으면 3단계를 다시 해요.
홈 화면 아이콘으로 열면 버튼이 없어요

아이콘이 웹 앱(주소창 없는 화면)으로 열린 거예요. 아이콘을 지우고 4단계에서 웹 앱으로 열기를 끄고 다시 추가해 주세요.

그래도 안 되면 단축어 앱 → + → URL 열기를 추가하고, 주소에 x-safari-https://learn.hoseo.ac.kr/my/?lmscheck 를 넣은 뒤 공유 버튼 → 홈 화면에 추가 하세요.

'Tap to install'이 안 보여요
  • 꼭 Safari에서 3단계 버튼을 눌러야 해요 (카카오톡 · 크롬 안 됨).
  • Userscripts 화면 위쪽에 아무것도 없으면 아래로 당겨 새로고침하거나, 이 페이지로 돌아와 버튼을 다시 눌러요.
안전한가요?

학교에서 만든 것이 아닌 개인용 비공식 도구예요. 이미 로그인한 LMS 화면 안에서 LMS 페이지를 읽기만 하고, 비밀번호를 다루지 않아요. 읽은 정보는 내 아이폰 Safari에만 저장되고 다른 곳으로 보내지 않아요. 학교 서버 부담을 줄이려고 처음 열 때와 새로고침 버튼을 누를 때만 LMS를 읽어요.
